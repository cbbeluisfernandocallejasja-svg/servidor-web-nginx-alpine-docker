# Evidencias

Capturas de pantalla y resultados de las pruebas.

## Cómo nombrar los archivos

`EVID-XX_descripcion-corta.png`, por ejemplo `EVID-06_sitio-desde-celular.png`.

## Reglas

- Cada captura corresponde a una prueba realmente hecha.
- **Ninguna captura debe mostrar contraseñas, tokens ni datos sensibles.**
- La captura de la prueba desde otro dispositivo debe mostrar la dirección IP en la barra del navegador.
